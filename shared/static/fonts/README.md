# Website fonts

Self-hosted WOFF2 files with `font-display: swap`. Every family is under the SIL Open Font License 1.1; keep each
licence file beside the fonts it covers.

- **IBM Plex Sans**, the text font: `IBMPlexSans-Regular.woff2`, `IBMPlexSans-Italic.woff2` and
  `IBMPlexSans-SemiBold.woff2`, unchanged from `fonts/complete/woff2/` of the npm package `@ibm/plex-sans` 1.1.0.
  Licence: `IBMPlexSans-LICENSE.txt`.
- **Jersey 10, 15, 20 and 25**, the font of headings and navigation, one cut for each size:
  `Jersey10-Regular.woff2` and the three like it, converted with `ttf2woff2` from the `.ttf` files in
  [Google's fonts repository](https://github.com/google/fonts/tree/main/ofl) (`jersey10`, `jersey15`, `jersey20`,
  `jersey25`). Licence: `Jersey-OFL.txt`, the same text for all four.
- **Jacquard 12**, declared in the stylesheet and not used yet: `Jacquard12-Regular.woff2`, converted the same way
  from `jacquard12` in the same repository. Licence: `Jacquard12-OFL.txt`.
- **Pixel Code**, the code font: `PixelCode.woff2`, `PixelCode-Italic.woff2` and `PixelCode-Bold.woff2`, unchanged
  from `dist/woff2/` of [its repository](https://github.com/qwerasd205/PixelCode) at commit `eefe418`. Licence:
  `PixelCode-LICENSE.txt`.
