# Website fonts

Self-hosted WOFF2 files with `font-display: swap`. All three families are under the SIL Open Font License 1.1; keep
each licence file beside the fonts it covers.

- **Jersey 15**, the text font: `Jersey15-Regular.woff2`, converted with `ttf2woff2` from `Jersey15-Regular.ttf` in
  [Google's fonts repository](https://github.com/google/fonts/tree/main/ofl/jersey15). Licence: `Jersey15-OFL.txt`.
- **Jacquard 12**, declared in the stylesheet and not used yet: `Jacquard12-Regular.woff2`, converted the same way
  from `Jacquard12-Regular.ttf` in
  [Google's fonts repository](https://github.com/google/fonts/tree/main/ofl/jacquard12). Licence:
  `Jacquard12-OFL.txt`.
- **Pixel Code**, the code font: `PixelCode.woff2`, `PixelCode-Italic.woff2` and `PixelCode-Bold.woff2`, unchanged
  from `dist/woff2/` of [its repository](https://github.com/qwerasd205/PixelCode) at commit `eefe418`. Licence:
  `PixelCode-LICENSE.txt`.
