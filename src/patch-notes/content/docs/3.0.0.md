WarCraft III: Reforged - Patch 3.0.0

## **General**

- Added new UI Theme \- Forsaken Kingdom
- Added new Music \- Forsaken Kingdom
- Added new first time launch cinematic
- Max selection group increased from 12 to 24
- Added unit occlusion
- Added air to ground indicators for HD graphics
- Campaign flow screen has been updated
- Updated IBL maps for better visual fidelity in HD modes
- Players can now choose what graphic they want in the mission select screen
- Players can unlock progress of the campaign regardless of what mode they are playing in (IE Playing Classic Human Campaign will also unlock progress in Reforged Campaign)
- Added new DLC Campaign (requires purchase of Forsaken Kingdom)
- The Last Days of Lordaeron
- Forsaken Kingdom
- Game now supports OOG audio files
- Floating text cap increased to 10k
- New stats added: Ability Amp, Ability Vamp, Ability Speed, Mana Efficiency, Crit Chance / Damage, Ability Crit Chance / Damage, Resolve
- Main Menu now changes music theme and ambient sound depending on selected UI Theme
- Classic HD has now been replaced with a new mode Definitive Edition
- Addon system has been deprecated, players can now choose between Classic, Definitive Edition and Reforged
- 1.36 Terrain has been re-added to Reforged Mode
- Improved water for HD
- Improved fog of war in HD for large doodads and destructibles
- Unlimited lights in HD
- Culling fixes for doodads and terrain images

  ## **Neutral Hero**

- New [Tavern](https://liquipedia.net/warcraft/Tavern) Hero Added \- [Forsaken Paladin](https://liquipedia.net/warcraft/Forsaken_Paladin) for SD, DE, and HD

  ## **Custom Lobbies**

- Custom Game Lobbies can now be password protected

  ## **Networking**

- Added new game servers in the following locations:
  - Jurong West, Singapore
  - Osaka, Japan
  - Delhi, India
  - Saint-Ghislain, Belgium
  - Melbourne, Australia
  - Toronto, Ontario, Canada
  - Osasco, São Paulo, Brazil
  - The Dalles, Oregon, USA
  - Hamina, Finland
- Lan mode has been removed (players can still play LAN via the Classic Client)
- Reforged client now requires players to be\< online at all times (offline mode still available via the Classic Client)

  ## **Options**

- Added new options for Point Light Shadows, Water and Supersampling
- Removed Ambient Occlusion, Bloom, Portrait Bloom, Particles, and Spells.
- Renamed Shadows to Environment Shadows
- Added new campaign tab in hotkeys menu for campaign units

  ## **World Editor**

- Added new lighting editor
- Doodads are now able to be rotated with pitch and roll
- Doodads and items can now have team color assigned
- Added editable omni lights
- Added shadow casting omni lights
- Can view shadows and fog in HD
- New HD water
- Added doodad decals in HD
- Added water doodad in HD
- Added shadow blocker doodads in HD
- Added more fog options (height fog, new exponential, draw over sky, max opacity)
- Live editing of fog and HD water settings
- Players can now assign team color to destructible, doodads and items
- Added new alpha tile functionality
- Added the ability to paint the mini map with different colors
- Added option for the minimap to be generated dynamically within camera bounds
- Added new equipment category
- Added new category for item instances
- Added option to choose HUD skin (including new Forsaken HUD) per player
- Added free camera
- Added the ability to freely edit the file path of an existing sound variable
- Added new native to reset a unit's attack cooldown
- Added new native to set the remaining cooldown duration of a unit's ability
- Added new native to enable or disable all aura abilities of a unit
- Added "Copy As Script" option for triggers
- Added option to convert triggers to Lua
- Objects can now be scaled along their local axes instead of world axes
- Added a gameplay constant for AI call for help range
- Added option for copied objects to preserve their height
- Added various new ability natives
- Added a post processing tool to apply post-processing effects at map level
- Added a tool to adjust string IDs
- Added data editor option to display HP of invulnerable buildings
- Added GUI interface to leak cleaning natives
- Added light range visualization
- Added flag to disable HD shadow
- Refactored GUI interface of some natives, as well as their built-in documentation
- Increased default undo stack size, user configurable to near infinite

  ## **Bugfixes**

- Fixed various Save/Load issues regarding LUA serialization
- Fixed an issue where mini-map icons would not scale with HUD scale
- Fixed an issue where map makers could not change the race crest of their map or decide if to have one at all
- Fixed non-en Keyboard layout for login entry
- FIxed .tif file imports crashing the world editor on map load
- Fixed an issue where projectiles would not appear if target was too close to the caster
- Terrain images without a transparent border no longer render beyond their file's pixels
- Fixed an issue where spawning new lightning effects would remove old ones
- Fixed an issue that would erroneously reset a custom campaign map custom loading screen
- Fixed an issue that would corrupt map imports in custom campaigns
- Fixed an issue that would cause custom campaign and AI editor to open up with the wrong dataset
- Terrain images now follow walkables
- Fixed several editor UI rendering bugs with regions and selections
