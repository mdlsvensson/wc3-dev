Build **Defend the Village**, a small map where you hold a village against five waves of gnolls and ogres. You start from an empty map and finish with a playable game using the World Editor that comes with Warcraft III: Reforged — no programming required.

- **6 chapters** · **21 lessons** · **About 5 hours 25 minutes**
