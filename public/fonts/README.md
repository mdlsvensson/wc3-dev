# Website fonts

Self-hosted WOFF2 files with `font-display: swap`.

- **Mona Sans**: normal and italic variable webfonts from
  [GitHub's official repository](https://github.com/github/mona-sans/tree/main/fonts/webfonts/variable),
  the family available on [Google Fonts](https://fonts.google.com/specimen/Mona+Sans).
  Original filenames: `MonaSansVF[opsz,wght].woff2` and `MonaSansVF-Italic[opsz,wght].woff2`.
  License: `Mona-Sans-OFL.txt`.
- **Monaspace Argon 1.400**: `Monaspace Argon Var.woff2` from the
  [official v1.400 release](https://github.com/githubnext/monaspace/releases/tag/v1.400),
  `monaspace-webfont-variable-v1.400.zip`.
  License: `Monaspace-LICENSE.txt`.

Downloaded September 21, 2026. Keep the license files with redistributed fonts.
