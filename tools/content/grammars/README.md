# Vendored grammars

`yuescript.tmLanguage.json` is the TextMate grammar of the VS Code extension YueScript (`LiJin.yuescript`), version
0.2.10, from <https://github.com/pigpigyyy/yuescript-vscode>, file `syntaxes/yuescript.tmLanguage.json`. It is
unchanged. Its licence is `LICENSE.md` beside it (MIT) and must stay with it.

It is read only while content is prepared. Nothing here reaches the browser or the Worker.
